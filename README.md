# rofi-zed

![Demo](./docs/demo.mp4)

Quickly open recent Zed Editor projects with Rofi.

## Usage

### As a Rofi mode

```sh
rofi -show zed -modi zed
```

### With [combi mode](https://davatorium.github.io/rofi/current/rofi.1/#combi)

```sh
rofi -show combi -combi-modi drun,zed,ssh
```
